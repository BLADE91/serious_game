## 20.0 全局口径与恒定不变量（先读这一段）

| 事项 | 裁决 | 出处 |
|---|---|---|
| 旗标类型 | §7.5 登记的**每一枚旗标类型恒为「布尔」**，取值仅 真/假 | 【源自剧本 L2242 铁律】 |
| 旗标初值 | §7.5 登记的**每一枚旗标初值恒为「假」（false）**，开局无一为真 | 【源自剧本 L2242 铁律】 |
| 引擎唯一识别的旗标动作 | 仅 `开启旗标：X`（置真）/ `关闭旗标：X`（置假）两式；「强化 / 加成 / 叠加 / 置位」等一律不被引擎识别 | 【源自剧本 L999】 |
| 未登记旗标名 | 只作**存档剧情痕迹**，引擎对其不做任何判定 | 【源自剧本 L999】 |
| 埋点/回收铁律 | 每枚旗标必须既有埋点（set）又有回收（read）；不得读一枚永不为真的旗标（孤儿旗标违规） | 【源自剧本 L2242】 |
| 结局不读指标 | 结局由「决策 + 旗标 + 人物终态」三合一推出，**不读体感/数值指标分箱**，无加权综合分 | 【源自剧本 L704–706】 |

**本总表的机读列范式（六列 schema）**

标准 schema：`中文名 | 英文键 | 类型 | 初值 | set位置(章-决策点-选项) | read位置(去向)`。

因 `类型` 与 `初值` 对 §7.5 全部登记项**恒为 `布尔 / 假`（L2242 铁律，无一例外）**，为免 360 行冗余复写，下列各束表**只渲染四个可变列**：`中文名 | 英文键 | set线索/登记行 | read去向`。每一行的 `类型` 一律读作 `布尔`、`初值` 一律读作 `假`，不再逐行复写。

**关于 set位置(章-决策点-选项) 的诚实说明**：§7.5 登记表按「束」登记旗标名，多数只给旗标名与（部分）read去向，**并未在登记表内钉死每枚旗标的 set 坐标(章-DP-选项)**。set 坐标的逐一映射由姊妹篇《30 动作与行动点效果规格》交付。本篇 `set线索/登记行` 列填写**该旗标在 §7.5 的登记行号 L####**（= 定义处），并在登记表已给出结算/read去向时如实抄录；凡登记表未标专属读点者，标注「登记表未标专属读点；见互斥组/结局区正文」，**绝不编造 set/read 坐标**。

> **覆盖声明**：本表须覆盖 §7.5 全部登记项。下列各束已逐项抄录本篇通读 §7.5（剧本 L995–L1759）所确认的全部旗标；未列尽者按同格式续抄。表尾给出转录计数。
