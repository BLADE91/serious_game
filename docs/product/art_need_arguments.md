# 《浊流之上》人物与场景美术需求及生成提示词

## 1. 文档范围

本清单依据 `最终剧本.md` 提取人物、可复用场景、关键事件插图和 24 个主结局封面，视觉风格以 `docs/product/美术设计/设计参考/` 下 15 张参考图为准。

本文件只解决“需要画谁、画什么场景、如何生成概念稿”。UI 组件、图标、证据文档、地图交互图层和字体排版不在本清单内。图片内不要生成可阅读的长段中文；标题、姓名、职务、数值、按钮和公文正文均由前端叠加，避免错字和后续剧本修改导致返工。

### 1.1 资产规模

- 独立人物设定：30 人。其中玩家角色 1 人、县委书记 1 人、23 名主要 NPC、5 名配角。
- 事件角色模板：血铅患儿与家属、巡察组随员、电视摄像师、村民群像、工作组干部群像。
- 可复用场景背景：24 张。
- 关键事件插图：12 张。
- 主结局封面：24 张；亚结局通过文案、色调和局部叠加层复用，不另画 95 张。

## 2. 统一风格与提示词规则

### 2.1 从参考图提炼的美术语言

- 半写实手绘水彩与轻厚涂结合，人物和场景接近纪实插画，不做照片滤镜。
- 中国中部山区县城与临江村庄，2026 年，但基层办公室、档案柜、搪瓷杯、旧桌椅和村屋保留明显年代使用痕迹。
- 低饱和配色：炭黑、墨绿、旧纸米黄、土褐、灰蓝；朱红只用于印章、风险、横幅和极少数视觉焦点。
- 光线克制，阴天漫射光、夏季潮湿雾气、钨丝灯与办公室冷白灯交替出现。
- 人物脸上要有年龄、职业、劳作、压力与生活痕迹；干部之间、村民之间必须有明显辨识差异。
- 暗线人物不能画成反派脸；冲突来自神态、距离、手部动作、物件和构图，不来自夸张阴影或邪恶表情。
- 画面允许有旧纸纹理和颗粒，但纹理不能覆盖人物五官和主要叙事物件。

### 2.2 人物通用正向提示词

> 中国县域基层治理题材，半写实手绘水彩与克制厚涂结合，纪实插画质感，2026 年中国中部山区县，低饱和炭黑、墨绿、土褐、灰蓝和旧纸米黄配色，柔和漫射光，真实亚洲人面孔，明确年龄与职业痕迹，皮肤纹理自然，服装符合基层干部或乡村生活，头肩胸像，3/4 侧面，档案卡人物肖像，背景轻度虚化，细腻笔触，严肃、克制、有泥土味，不使用真实人物肖像。

### 2.3 场景通用正向提示词

> 中国中部山区县域治理题材，半写实手绘水彩场景，轻厚涂，低饱和墨绿、土黄、灰蓝、旧纸米黄，夏季潮湿空气与清江薄雾，真实基层办公室和乡村生活细节，纪实构图，克制的制度压力感，16:9 横幅，层次清楚，主体不拥挤，为游戏对话框和选项面板预留低细节安全区，不生成可读文字。

### 2.4 通用反向提示词

> 真实照片，明星脸，政治人物肖像，网红脸，磨皮，美颜，夸张反派脸，二次元，卡通大眼，商业手游卡牌，赛博朋克，霓虹，高饱和，奇幻，武侠，民国服装，古装，豪华都市办公室，欧美乡村，过度破败，恐怖血腥，枪械，夸张戏剧光，鱼眼畸变，多余手指，错误手部，重复人物，水印，logo，二维码，可读中文乱码，文字占据画面。

### 2.5 一致性要求

同一人物的全部差分必须复用同一角色设定、脸型、发型、服装主色和随身物件。先锁定中性头像，再以中性头像做参考生成 `trust / tense / angry / worried / resistant` 差分。所有干部都穿符合县域日常工作的夹克、衬衫或简洁西装，避免人人黑西装；所有村民也不能统一为“贫困老人”造型。

## 3. 人物设计清单

### 3.1 玩家与县委核心人物

- 描述：省里空降，经济学博士，曾任市发改委副主任。理性、受过良好教育、履新不久，既有主官的克制权威，也保留尚未被县域关系网磨平的锐气。作为玩家化身，神态不能预设清廉、腐化、强硬或怀柔结局。

- 建议差分：neutral、resolute、tired、pressured。
- 资产 ID：`player_li_zhiyuan_portrait_neutral`；manifest 使用 `linked_entity_type=player`、`linked_entity_id=player_li_zhiyuan`。

- 剧本地点是云溪县、柳林村、清江、渡口镇、宏达化工；参考图里的青河县、上游村、中游村、下游村等旧名不得照搬。
- 界面不应直接展示人物信任度数值、旗标、隐藏指标或结局条件；美术只提供神态和事件氛围，是否可见由前端规则控制。
- 游戏没有综合评分和唯一正确答案。结局图不要放星级、奖杯、S/A/B 评级或“达成/失败”大印章；正式文本由结局页动态渲染。
- 24 个主结局有 95 个亚结局。亚结局应使用同一主图的局部变化、色调差分或小物件叠加，避免把亚结局制作量误算成 95 张独立大图。
- 祖坟与起灵场景要尊重地方礼俗，不展示遗骨，不制造恐怖气氛。
- 血铅患儿场景只表现医疗与制度责任，不消费儿童痛苦，不展示侵入性医疗特写。
