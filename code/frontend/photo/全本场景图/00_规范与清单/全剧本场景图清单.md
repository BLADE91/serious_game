# 《流域抉择》全剧本场景图清单

## 一、交付范围

- 正文场景图：48 张，覆盖六章九十天。
- 主结局图：24 张，每个主结局一张；亚结局沿用对应主结局画面并通过文字与界面状态表现差异。
- 总计：72 张。
- 每张图均保存最终源图、游戏用 WebP、提示词和剧情出处。

## 二、统一美术规范

- 画面比例：16:9。
- 基准尺寸：1672 × 941；游戏版另输出高质量 WebP。
- 风格：写实、克制、具有中国中西部山区县城纪实感的环境概念图。
- 年代：约 2008—2015 年的县域基础设施与室内陈设，不出现现代智能大屏、摩天楼或未来设备。
- 色彩：清江青绿、旧木暖褐、纸张米白、县域灰蓝；整体可读，不使用重度黑色遮罩。
- 摄影：以玩家视点或略高于人眼的观察视角为主，场景真实、有生活痕迹。
- 人物：正文背景原则上不出现清晰正脸，人物由网页人物卡承担；群众事件可出现无明确身份的远景人群。
- 文字：画面不生成可读文字、标语、文件正文或水印；具体文字由网页原生图层呈现。
- 连续性：县政府、县委小楼、柳林村、清江、宏达旧厂区、周氏祠堂、县医院在不同图片中保持建筑材料、年代与地域气质一致。
