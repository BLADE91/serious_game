# 统一提示词基底

以下内容附加到每张场景图的专用提示词中，用于保持全剧本视觉连续。

## 正文场景

Use case: historical-scene  
Asset type: serious narrative game scene background  
Style: photorealistic environmental concept art, restrained Chinese county documentary realism, cinematic but not theatrical  
Setting continuity: a poor mountainous county along the Qingjiang River in inland China, approximately 2008–2015  
Camera: 16:9 landscape, player-eye observational viewpoint, natural 28–35mm lens, clear foreground/midground/background hierarchy  
Palette: Qingjiang green, weathered timber brown, warm paper beige, muted county-government gray-blue; readable midtones, no crushing black  
Materials: worn terrazzo, aged plaster, dark wood, enamel mugs, kraft-paper files, damp stone, old tile roofs  
Character rule: no clearly identifiable protagonist face; background figures only when the plot requires a crowd  
Text rule: no readable text, no logos, no watermark, no interface, no subtitles  
Avoid: futuristic equipment, modern luxury interiors, skyscrapers, neon cyberpunk, exaggerated poverty spectacle, horror styling, fantasy elements, English text

## 结局图

Use case: stylized-concept  
Asset type: serious narrative game ending key art  
Style: photorealistic symbolic realism, restrained political drama, grounded objects and locations rather than fantasy metaphor  
Composition: 16:9 landscape, one strong visual focus, generous negative space for ending title overlay  
Continuity: reuse the same Yunxi County, Liulin Village, Qingjiang River, county offices and paper-file visual language  
Lighting: emotionally specific but still natural and readable  
Text rule: no readable text, no logo, no watermark  
Avoid: propaganda-poster style, supernatural symbolism, excessive darkness, melodramatic facial close-ups, English text

## 画面验收

每张图生成后检查：

1. 地点是否与剧本相符。
2. 宏达旧厂区、拟建厂址、旧冶炼遗址是否被错误合并。
3. 柳林村是否仍为河湾村落，渡口是否被误画成公路桥。
4. 人物年龄、身份和服饰是否符合县域干部、村民与记者身份。
5. 是否出现现代大屏、豪华办公楼或年代不符的设备。
6. 是否出现不可控的错误文字。
7. 画面是否足够明亮，适合网页长期阅读时作为配图。
8. 是否预留界面叠加空间。
