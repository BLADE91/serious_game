# 《流域抉择》全剧本场景图交付说明

## 数量

- 正文场景：48 张。
- 主结局：24 张。
- 合计：72 张。
- 每张正式图均有同名 PNG 与 WebP 两种格式，尺寸统一为 1672 × 941。
- 每张正式图均有独立提示词文件，共 72 份。

## 文件夹

- `00_规范与清单`：完整场景清单、统一美术规范与提示词基底。
- `01_第一章_迷雾初现` 至 `06_第六章_验收之日`：正文场景。
- `07_结局`：24 个主结局场景。
- `08_提示词`：按场景编号一一对应的提示词。
- `09_源图`：迭代中淘汰的源图，便于追溯，不用于游戏。
- `10_缩略图画廊`：正文、结局和全 72 张联系表，以及可筛选的本地浏览索引。

## 使用建议

- 前端游戏页面优先加载 WebP，点击查看大图或后续加工时使用 PNG。
- 场景图中的文件标题、提示牌、地图标注等精确信息继续由网页原生图层承载，避免图片内文字失真。
- 正式接入只读取章节文件夹与 `07_结局`，不要读取 `09_源图`。
