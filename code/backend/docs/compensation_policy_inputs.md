## 还需确认的计算规则

这些不是金额，但必须与数字一起定稿：

1. 房屋、土地、人口的认定基准日。
2. 无证房、历史形成房屋、超建面积和权属争议的处理比例。
3. 一户多宅、分户、空挂户口和已外迁人口的认定规则。
4. 安置房与货币补偿能否组合，选择后能否变更。
5. 个别困难兜底是否占用8000万元专项总盘；若不占用，资金科目与总上限是多少。
6. 宏达6000万元是固定出资额、最低承担额还是谈判底线；何时到账、能否分期。
7. 200万元前期协调费是已从8000万元中扣除，还是另列项目费用。
8. 奖励是否计入补偿总盘，以及不同批次是否允许不同奖励。
9. 迁坟择地、仪式和后续祭祀设施的非现金责任由谁承担。
10. 所有数值在游戏中是固定公开、按章节调整，还是由正式决策点在有限区间内选择。
