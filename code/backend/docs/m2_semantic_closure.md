# M2 剧本语义闭环清单

更新时间：2026-07-18

本清单以 `最终剧本.md` 为唯一内容权威，记录 M2 运行时对容易产生歧义的条件、延迟结算与结局规则的实现口径。它不是第二份剧本；母稿变化后必须重建剧本包并重新运行完整校验与测试。

| 语义项 | 运行时口径 | 自动化守卫 |
|---|---|---|
| 签约目标线 | 真实签约户数 `<30` 为一票否决；`30–31`、`32–33`、`≥34` 分别映射轴 A 的压线、宽裕、全额。不存在“30–36 户统一触发一个结局”。 | D90 结局前守卫只在 `signed_households >= 30` 时开启“最后一公里攻坚成功”；结局仍按 24 行主结局表首命中。 |
| 34/35 户终局文案 | 轴 A 仍为母稿规定的“全额”，但叙事不得虚称 36 户全部签满，输出使用实际户数。 | 34、35 户均有回归测试。 |
| 结局可达性 | 24 个主结局按母稿表序自上而下首命中，95 个亚结局是内容接口集合，不要求每局或每种自然路径全部触发。被高优先级主结局遮蔽不视为运行错误。 | 包校验固定 24/95/3 的完整性、归属关系与第 24 行恒真兜底。 |
| 提前强制决策 | DP2-03 在 D19 且“压下账目”时提前；DP2-04 在 D21 且“已立项审计”时提前。提前进入后不在原排程日重复。 | 早触发旗标、日窗和队列唯一性由加载器与故事流测试覆盖。 |
| 延迟重选 | EV3-01 选择上交矛盾后，次日只能在 A/B/C 中重选，且代价加重；原选择旗标在重选结算后关闭。 | `ev3_01_followup` 为独立强制节点，进入故事时钟校验。 |
| DP4-04 迁坟谈判 | 谈钱最多连续两次；第三次仍谈钱才完成。先谈过钱或未掌握祖坟信息时，礼俗方案走“条件待议”回退，不得直接拿到完整收益。 | 待决策 `context` 持久化并经过 SQLite codec 往返测试。 |
| 恢复路径 | 谭老六、袁桂兰和周满仓的母稿补救入口作为受日窗和前置旗标约束的付费互动机会；周满仓互动后进入两段恢复决策。 | 32 个机会及其完成结算、事实、旗标、后续决策引用均由包加载器校验。 |
| 预算与禁选 | 需要支出的选项读取剩余预算；DP4-08 A 在预算不足 22 万元时禁选。围堰已漫溢未处置时，EV4-04 B 禁选。 | 选项支持台账最小值/最大值条件，未知条件字段会使发布包加载失败。 |
| 章节加班上限 | EV1-02 的加班选项在本章已加班三次后不可再选。 | `chapter_overtime_count <= 2` 是选择前置而非结算后补救。 |
| DP5-10 蒋崇岳态度 | A 仅在两份证据齐全时获得支持，恰有一份为默许，两份皆无为放弃；B/C/D 为放弃，E 为实情未上桌。 | 支持、默许、放弃三态互斥；规则层禁止一次写入多个态度。 |
| DP6-10 最终表决 | 公开议程且没有既有支持时进入否决；已有支持但选择 C 时转为放弃；已有支持且选择 A/B 时保留支持。 | 由运行时根据既有状态和选项派生，内容包不得自行写出互相冲突的态度。 |
| 第五章条件修正 | DP5-06、DP5-07、DP5-09 的审计/党员档案、补偿说明、口头承诺、文字阻断和周满仓受压修正均作为条件结算执行。 | 条件结算的旗标、状态与台账字段均在发布包加载时校验。 |
| 夜间模拟 | D1–D89 每日只生成一次夜间日志；关键夜戏使用母稿文本块和条件结算，其余日期使用确定性日终痕迹承接状态。 | 日终幂等、重启恢复、29 个文本锚和 9 条条件夜间规则纳入回放测试。 |

## 发布包完成口径

- 90 个 story beat 无重叠覆盖 D1–D90。
- 62 个编号 DP、14 个编号 EV、4 个配套运行节点，共 80 个可提交决策、684 个选项。
- 29 名 NPC 均有可用性登记；连同 3 个条件恢复入口，共 32 个互动机会。
- 18 条结构化事实/线索、8 个地图地点、24 个主结局、95 个亚结局和 3 个附加位全部通过交叉引用校验。
- 发布包锁定母稿 SHA-256、逐文件哈希和聚合内容哈希；重建后必须通过后端、终端及根目录剧本工具测试。

真实角色 LLM、成本控制、长期记忆压缩和对抗难度属于 M3，不属于 M2 完成条件。
