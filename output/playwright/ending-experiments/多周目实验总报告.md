# pkg_gameplay_v3 多周目结局实验总报告

## 1. 实验目标与范围

本轮验证 `pkg_gameplay_v3` 的 24 个主结局、95 个亚结局是否能由普通玩家路径自然到达，并用完整 D1→D90 周目确认首命中表序。所有计入实验的路线均从全新存档开始，仅使用浏览器控件或合法公开玩家 HTTP 行为；未修改数据库、session state、快照、隐藏字段、生产代码或测试。

## 3. 方法与控制变量

共形成 31 份独立周目报告：RUN-01 是首个 headed UI 完整长跑；RUN-02–29 为公开 API 玩家客户端完整路线/attempt（其中失败探针也单独成报告）；RUN-30/31 由 headed Chromium 创建新局、合法公开 API 驱动同一 session、浏览器复核关键时间线和 D90，分别覆盖公开治理与高压结局。

每局控制项：全新 v3 存档、相同 Fake 模型、D1 开始、逐日推进、D90 结算、合法公开请求、无状态直改。合同路线均通过可见代表人物/诉求、批次确认、逐户条款、专业审校和正式签署。D76 后公开签约奖励统一提交 false。

## 11. 玩家体验总结

核心治理路线的分流总体清楚：早期证据处置会保留到 D90，媒体、班子、群众关系和推进方式的相互遮蔽可从结局轴理解。合同从代表会谈到逐户签署的权威链足以支撑 28/29/30/33 户等精确阈值实验。

当前最大的内容缺口不是“结局数量少”，而是四份不可呈现资产：三个理想/悲壮结局被缺失的治理闭环阻断，一个兜底结局被表序穷尽。修复前的结局卡问题会让玩家九十天后完全看不到成果，55e4fa 已消除这一致命体验断点。
