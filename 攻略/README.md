# 《浊流之上》结局攻略

> 严重剧透：本目录公开结局名称、结局轴和关键选择。

本攻略依据 v3 `3.5.12-map-coverage` 的 95 条已通过合法路线、3 条真实 API D1–D90 通关记录及当前结局规则编写。

## 怎么使用

1. 先在[24 个主结局攻略](24个主结局攻略.md)中选择目标。
2. 按“核心条件”和“推荐操作”控制主结局。
3. 再到[95 个子结局速查](95个子结局速查.md)选择后缀。
4. 遇到内部决策编号时，到[关键选择对照](关键选择对照.md)查找玩家实际看到的选项文字。

## 结局判定最重要的规则

- D90 不是简单按最后一次选择判定，而是综合整局形成的 14 条结局轴。
- 主结局有优先级。系统从 `ending_01` 到 `ending_24` 依次匹配，第一个满足条件的主结局生效。
- 子结局由该主结局的“自由轴”决定。例如《铁窗之内》固定要求腐败败露，但后缀由签约进度决定。
- 同一个关键选择可能影响多条轴；夜间会谈、人物关系、合同、档案和正式文书也会改变最终状态。
- 以下签约数是已经实际跑通的稳定控制点：27 户对应“溃败”，29 户对应“差一两户”，30 户对应“压线”，32 户对应“宽裕”，34 户对应“全额”。攻略建议使用这些精确数字，避免停在边界附近。

## 通用通关原则

- 想走圆满线：拒绝利益输送；真实台账；优先查档和核实；落实血铅复检、治疗和环境整改；不用暴力；至少签约 30 户，推荐 32 户；关键事项写入会议决议和正式文书。
- 想走失败或警示线：只改变目标结局要求的那一条轴，其余方面尽量保持稳定，否则更高优先级结局可能抢先触发。
- 想控制人物关系后缀：可信承诺要具体说明责任、期限和公开方式；空话或前后矛盾可能让夜间会谈无法收束或让人物重新追问。
- 想控制真相轴：取得证据不等于完成治理。“无知、知而捂、揭而未治、揭而已治”分别要求不同程度的调查、公开与落实。
- 想控制腐败轴：不要把“最后上报了”误认为可以抵消此前收受利益；《铁窗之内》的优先级最高。

## 证据范围

- 24 个主结局、95 个子结局：均有确定性合法路线通过。
- `ending_01a`、`ending_08a`、`ending_23a`：另有真实 `qwen3.6-plus` 完整 D1–D90 通关证据。
- 其余 92 个子结局尚未逐个使用真实 API 人工游玩，因此本攻略对它们采用“规则条件 + 已通过合法路线”的表述，不伪装成 95 次真人试玩。
